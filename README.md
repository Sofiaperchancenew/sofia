# Sofia — générateur Perchance
Jeu de rôle + panneau musique (packs Suno : Style + Structure + Paroles, 10 langues), galerie publique « sofia-chansons », lecteurs Suno intégrés, guide (Valeria, musique + copyright).
## Contenu
- main.pjs : listes et logique Perchance
- index.html : interface (contenu du body)
- src/ : modules (musique, i18n, données, éducation...)
## Notes musique
- Chansons créées par Sofia en mode musique ; compositions personnelles du concepteur réalisées avec Sofia.
- Copyright des paroles : le concepteur (Wayback Machine depuis les années 1990).
